# 🛍️ Customer Behaviour Analysis

## 📌 Overview

This project analyzes customer purchasing behaviour using an end-to-end data analytics workflow.

**Workflow:**  
CSV Dataset → Python → PostgreSQL → SQL → Power BI

## 🛠️ Tools Used

- 🐍 Python & Pandas: Data cleaning and preprocessing
- 🗄️ PostgreSQL: Data storage and analysis
- 🔍 SQL: Customer and sales analysis
- 📊 Power BI: Data visualization and dashboard

## 🔄 Process

### 1. Python
Cleaned the raw CSV dataset by handling missing values, duplicates, data types, and creating useful columns such as age groups.

### 2. PostgreSQL & SQL
Imported the cleaned data into PostgreSQL and performed analysis on:
- Revenue by category
- Customers by category
- Revenue by age group
- Subscription status
- Customer purchasing behaviour ,etc

### 3. Power BI
Created an interactive dashboard showing:
- Average Purchase Amount: **$59.76**
- Customers: **3.9K**
- Average Rating: **3.75**
- Revenue by Category
- Customers by Category
- Revenue & Customers by Age Group
- Subscription Status

## 🎯 Conclusion

The project provides insights into customer behaviour, sales performance, demographics, and subscription patterns using Python, SQL, and Power BI.
